# ISO 9001 Olgunluk Özdeğerlendirmesi — Havayolu

Yönetim sistemi olgunluk modeli (Yaklaşım × Uygulama, S = MİN(Y;U)) ve ISO 9001 gereklilik bazlı değerlendirme kriterleri.

## Dosyalar

| Dosya | İçerik |
|---|---|
| `Olgunluk_Modeli_v2.1_Gereklilik_Bazli.xlsx` | **Güncel model (v2.1).** 70 ISO 9001 gerekliliği; her biri için Y1–Y5 rubriği, bayrak ve süreç sahibi. Bütün sekmeler (Başla, Değerlendirme, Sonuç, Referans) ve formüller çalışır durumda. |
| `Olgunluk_Modeli_v2_Sadelestirilmis (new).xlsx` | Önceki model (v2.0, 61 soru). |
| `Book1.xlsx` | Kaynak gereklilik listesi (kural kodu, başlık, metin). |
| `Gereklilik_Bazli_Degerlendirme_Kriterleri.xlsx` | Yalnızca kriterlerin bulunduğu tek sayfalık çalışma dosyası. |
| `indirme_sayfasi/` | Kriter dosyasının indirme sayfası (HTML + veri). |

## Değerlendirici için kurallar

- Seviyeler birikimlidir: bir seviye için altındaki bütün seviyelerin koşulları sağlanmış olmalıdır.
- Kanıt gösterilemeyen koşul sağlanmamış sayılır; tereddütte alt seviye verilir.
- "Örneklemede" ifadesi, seçilen kayıtların tamamında koşulun görülmesi gerektiğini belirtir.
- J–N kolonları yalnızca Y (Yaklaşım) eksenini tarif eder; U (Uygulama) "Başla" sekmesindeki genel skalayla puanlanır.
